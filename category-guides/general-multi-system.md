# دليل المصادر العامة ومتعددة الأنظمة

**النظام:** عام / متعدد الأنظمة — `General / Multi-system`

## مقدمة النظام

المصادر العامة هي نقطة البداية الطبيعية حين لا تعرف بعد أي نظام سبب العطل، أو حين تتعامل مع سيارة لا تتوفر لها وثائق خاصة في تونس. تجمع هذه المصادر أدلة إصلاح لعلامات متعددة، وقواعد بيانات أكواد، ومخططات كهربائية عامة، لكنها لا تغني عن دليل الصانع عند تنفيذ إصلاح دقيق.

قوة المصدر العام أنه يمنحك المفردات الصحيحة: اسم النظام، وظيفة المكوّن، ومنطق التشخيص. وضعفُه أنه قد يخلط بين طرازات وسنوات مختلفة. لذلك اقرأ دائماً سنة الصنع ونوع المحرك وناقل الحركة قبل تطبيق أي خطوة، ولا تفترض أن إجراءً صالحاً لطراز 2015 صالح لطراز 2008.

استعمل المصادر العامة أولاً لبناء فرضية، ثم انتقل إلى مصدر متخصص أو إلى دليل الصانع لتأكيدها. سجّل ما قرأته: الكود، الشرط الذي يظهر فيه، والقياسات المتوقعة. هذه الملاحظات تختصر عليك ساعات عند العودة إلى الورشة أو عند طلب قطعة.

في السياق التونسي، المصادر العامة مفيدة بشكل خاص للسيارات المستوردة المستعملة التي تفتقد كتيّب الصيانة. لكنها تحتاج حذراً مضاعفاً: تحقق من رقم الهيكل (VIN) ومن مواصفات السوق، لأن بعض الأنظمة تُحذف أو تُضاف حسب بلد التسليم.

## كيف تستخدم المصادر

1. ابدأ بالبحث برقم الهيكل الكامل أو برمز المحرك، لا باسم العلامة فقط، لتضيق النتائج.
2. قارن بين مصدرين على الأقل قبل اعتماد قيمة مرجعية مثل عزم الربط أو ضغط الوقود.
3. افتح قسم «الملاحظات الفنية» أو «الخدمة» في الدليل قبل قسم الفك والتركيب؛ غالباً يذكر التحذيرات.
4. احفظ صفحة الإجراء أو اطبعها قبل العمل لأن بعض المواقع تتغير أو تطلب تسجيلاً لاحقاً.
5. تحقق من تاريخ آخر تحديث للمصدر؛ الإجراءات الأقدم قد لا تشمل أنظمة السلامة الحديثة.

## مصطلحات أساسية

| العربية | Français | English | التعريف |
| --- | --- | --- | --- |
| رقم الهيكل | Numéro de châssis (VIN) | Vehicle Identification Number (VIN) | سلسلة من 17 خانة تعرّف السيارة وطرازها ومحركها وسنة صنعها. |
| نظام | Système | System | مجموعة مكوّنات تؤدي وظيفة واحدة مثل التبريد أو الفرامل. |
| إجراء إصلاح | Procédure de réparation | Repair procedure | خطوات مرتبة لفك وفحص واستبدال مكوّن. |
| عزم الربط | Couple de serrage | Tightening torque | قوة شد البراغي بوحدة نيوتن متر، وتُحددها وثائق الصانع. |
| دليل الصانع | Manuel du constructeur | Manufacturer service manual | المرجع الرسمي لإجراءات ومواصفات السيارة. |
| رمز المحرك | Code moteur | Engine code | رمز يحدد عائلة المحرك وسعته وتجهيزه. |
| سنة الطراز | Année modèle | Model year | سنة تصميم الطراز، وقد تختلف عن سنة أول تسجيل. |
| ملاحظة فنية | Note technique | Technical bulletin | تعليمات إضافية يصدرها الصانع بعد بدء الإنتاج. |

## أخطاء شائعة

- تطبيق إجراء من طراز أو سنة مختلفة دون التحقق من رقم الهيكل ورمز المحرك.
- الاعتماد على فيديو واحد بدل مقارنة مصدرين أو ثلاثة.
- تجاهل التحذيرات الخاصة بفصل البطارية وأنظمة السلامة قبل الفك.
- نسخ قيم عزم الربط من منتدى غير موثوق بدل دليل الصانع.

## الأدوات المطلوبة

- كمبيوتر محمول أو هاتف للوصول إلى المصادر
- قارئ أكواد OBD-II
- مفك عزم (Torque wrench)
- دفتر ملاحظات أو تطبيق لتسجيل القياسات
- مصباح فحص قابل للشحن
